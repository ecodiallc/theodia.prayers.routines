# Theodia Prayer Routines

A dedicated repository of downloadable prayer routines for the Theodia app.

| File | Contents |
|---|---|
| `morning-prayer-lite.prayer-routine.json` | Short daily routine: Psalm of the day, Proverbs, silence, prayer list, Lord's Prayer |
| `evening-examen.prayer-routine.json` | Review the day with gratitude, confession, reflection, and surrender |
| `daily-office-lite.prayer-routine.json` | Psalm, Proverbs, creed, prayer list, Lord's Prayer |
| `family-prayer-time.prayer-routine.json` | Passage, Lord's Prayer, prayer list, short blessing |
| `workday-prayer-break.prayer-routine.json` | Silence, breath prayer, Scripture, prayer list |
| `sick-or-anxious.prayer-routine.json` | Psalm, fixed prayer for comfort, silence, reflection |
| `waiting-and-hoping.prayer-routine.json` | Lectionary, silence, reflection, free prayer |
| `grief-and-loss.prayer-routine.json` | Psalm of lament, fixed prayer, silence, journal prompt |
| `new-believer-starter.prayer-routine.json` | Apostles' Creed, Lord's Prayer, Psalm 23, silence |

## Source

Routines are authored by Theodia for ecumenical use across Christian traditions and Jewish practice where applicable.
